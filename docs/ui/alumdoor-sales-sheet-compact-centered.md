# Alumdoor Sales Sheet compact centered layout

UI-only presentation change for the unified Alumdoor Sales Sheet.

- Center table within the available sales workspace.
- Center headers, body cells, inputs, selects and Link triggers.
- Reduce default visual widths for Product, Color, Thickness, Height, Width, Area, Quantity, Rate, Discount, UOM and Amount.
- Keep existing Sales Sheet behavior, calculations, persistence and authority unchanged.
