# App Studio 360

App Studio composes modules, DocTypes, controllers/hooks, workflows, reports, print, dashboards, integrations, permissions, tests and release metadata. It does not allow visual actions to bypass kernels: business action is a typed handler package with capabilities, transaction/event contract and tests. Release graph must be acyclic and zero-unmapped; generated app can target CloudForge and MetaForge, with optional Frappe compatibility export where supported.
